# Governance

Xunfei Job Assistant is maintained by lazy consensus for routine work. The primary maintainer, [@mili-xi](https://github.com/mili-xi), has final responsibility for releases, security decisions, and resolving stalled changes.

Changes to `main` should flow through pull requests, tests, and review. Security fixes may be prepared privately and merged with a smaller disclosure footprint when public discussion would increase risk.

The project follows semantic versioning after `v1.1.0`. Release notes should state user-visible changes, security/privacy impact, known limitations, and verification evidence.

# Impact Evidence

This document records only evidence that can be verified from public sources after the repository is made public.

## Evidence Policy

Every curated evidence item must include a public source URL and UTC capture date. GitHub release asset `download_count` values are cumulative download events, not unique users, installations, external adopters, or monthly downloads. Maintainer smoke tests and self-downloads remain inside GitHub's raw counter and are never classified as external adoption.

External adoption requires an unsolicited public issue, downstream link, or published case study. Adoption issues are linked or quoted here only when optional citation permission is granted. No demo or self-authored adoption issue will be created.

# Security Policy

Please report vulnerabilities through GitHub private vulnerability reporting from the repository Security tab. Do not open public issues that contain credentials, resumes, recordings, private emails, or other personal data.

Supported version: `1.1.x` after the first public release.

The maintainer aims to acknowledge valid private reports within seven days. Fix timing depends on severity, reproducibility, and maintainer availability.

Credential incidents are handled rotate-first: revoke or rotate exposed provider credentials before public discussion, then remove the exposure path and document the safe remediation.
